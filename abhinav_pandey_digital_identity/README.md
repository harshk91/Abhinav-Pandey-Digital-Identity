# Abhinav Pandey — Digital Identity Website

A responsive, single-page digital identity profile built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and contact links
- `style.css` — responsive charcoal, silver and signal-red theme
- `script.js` — lightweight reveal effects and current copyright year
- `assets/` — reserved for optional images or assets later

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For hosting, upload the folder to a Git repository and deploy it with Vercel or Netlify as a static site.

## Before publishing
- Confirm the phone number, email and LinkedIn URL.
- Add an Instagram link only when the correct profile URL is available.
- Location, projects, CV, profile photo and Save Contact feature are intentionally omitted for now, as they have not been finalized.
- The chart-like illustration is decorative and is not live stock-market data.
- Skills are presented without proficiency percentages or claims of mastery.

## NFC setup
After deployment, write the final public website URL to the NFC sticker using an NFC-writing app. The sticker stores the URL; the website itself is hosted online. Test the NFC sticker on a second phone before sharing it.
